# WEATHER OBSERVATION ANALYSIS TOOL
A repository for Group 5 Project. 

## 1. Overview and Objectives
This program is a modular,menu-driven Python application designed to process weather observation data.It validates station readings,filters corrupted records with detailed failure explanations,calculates weather statistics,classifies temperature,and enables station search queries

## 2.Validation Constraints
-**Temperature**:Between -10°C and 50°C

-**Rainfall**:Zero or greater(>=0 mm)

-**Humidity**:Between 0%and 100%

-**Wind**:Zero or greater (>=0 km/h)

## 3.Menu Navigation
1.View valid readings.

2.Analyse weather.

3.Search by station.

4.View temperature classifications.

5.View invalid records.

6.View Summary.

7.Exit.
